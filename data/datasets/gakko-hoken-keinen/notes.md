# 変換ノート — gakko-hoken-keinen

## 出典と取得

- 学校保健統計調査(文部科学省、統計コード 00400002)の各年度確報「都道府県別 年齢別 疾病・異常被患率等」(平成24〜27年度=表9、平成28年度以降=表8)。e-Stat の統計表ファイル(Excel)を直リンクで取得(2026-07-20)。取得記録・statInfId 一覧・公表資料 PDF は `raw/ACQUISITION.md` を参照。
- e-Stat DB は 2019年度分で更新が止まっており、CSV 提供もないため、年度別 Excel が経年収録の唯一の経路(取得時に実測)。

## 収録範囲の判断

- **12歳(中学1年生相当)・計(男女計)に限定**: 都道府県別の公表は年齢別(5〜17歳)のみで、小学校計・中学校計といった学校段階別の県別値は存在しない。12歳は永久歯の1人当り平均むし歯（う歯）等数が公表される唯一の年齢であり、う蝕統計の国際比較でも標準年齢のため、県間・経年比較の軸として採用した。
- **指標は3つ**: むし歯（う歯）計・裸眼視力1.0未満計・永久歯の1人当り平均むし歯（う歯）等数(計)。処置完了者/未処置歯のある者の内訳は単年データセット(gakko-hoken-r7-todofuken)側に収録。
- **断層(令和2〜5年度)の扱い**: 令和7年度公表資料の注記(逐語)「令和２年度から令和５年度の数値については、いずれの項目も調査時期の異なる数値を含んでいる影響があるため、他の年度の数値と比較はできない」。運営者の決定(2026-07-20)により、**全年収録した上で該当4行の備考列に「調査時期の影響により他年度と比較不可(文部科学省注記)」を明示**する方式を採用(空欄化・行除外は不採用)。値そのものは各年度の公表値として正しいため保全し、経年比較の可否だけを行単位で注記する。
- 平成23年度以前は東日本大震災の欠測(岩手・宮城・福島)などの検討が別途必要なため、本版は平成24年度を起点とした。

## 抽出の要点(新旧レイアウト)

- 12歳・計はどの年度も **39シート中8番目「(39-8)」**。シートのタイトルに「12歳」「計」を含み「男」「女」を含まないことを assert してから読む。
- **新レイアウト(令和3〜7年度)**: ラベル列0。裸眼視力1.0未満計=列10 / むし歯（う歯）計=列19 / 処置完了者=列20 / 未処置歯のある者=列21 / 平均むし歯等数(計)=列27。タイトル行が年により行1〜2で揺れるため動的に特定し、ヘッダ3段(+2/+3/+4行)の文言一致を assert。令和3・4年度は「1.0未満」の中間見出しセルがなく DMF 計が「計（本）」表記の変種(列位置は同一)。
- **旧レイアウト(平成24〜令和2年度)**: ラベル列1(「全　　　国」「沖　縄　県」のように全角空白入り。平成24年度のみ「沖　　　縄」と接尾辞なし)。裸眼視力1.0未満計=列12 / むし歯=列21〜23 / 平均むし歯等数(計)=列29。平成24年度のみ旧 .xls だが列位置は同じ。
- 値は公表 Excel の表示文字列(SheetJS raw:false)をそのまま保持。全国=小数第2位・沖縄県=第1位という原表の桁数を含めて逐語。
- 記号の規約(令和7年度「調査の概要」逐語): 「－」=計数がない場合 / 「0.00」=計数が単位未満 / 「…」=調査対象とならなかった場合 / 「X」=標本サイズが小さい、又は標準誤差が大きいため統計数値を公表しない場合。沖縄県・全国の収録6値に記号は現れない(全値非空を assert)。

## 検証の記録(2026-07-20)

- 各年・沖縄県/全国の両行で「処置完了者+未処置歯のある者≒むし歯計」の恒等式を機械検証(独立丸めの許容差: 全国0.0151 / 沖縄0.151)。14年×2行すべて通過。
- 令和7年度の6値が単年データセット gakko-hoken-r7-todofuken の全国・沖縄県の値と完全一致することを変換時に assert(系列の接続確認)。
- 取得時に subagent が独立に読み取った記録(`raw/ACQUISITION.md` のスポット値)と一致: 平成24(全国42.78/沖縄72.0)・平成27(37.82/62.4)・令和元(31.76/51.6)・令和6(25.11/45.9、裸眼55.73/56.3、DMF0.53/1.4)・令和7(23.09/40.0、裸眼53.52/57.4、DMF0.47/1.0)。
