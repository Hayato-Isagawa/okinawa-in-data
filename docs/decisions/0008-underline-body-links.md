# 0008. 本文と出典のリンクは平常時も下線とアクセント色で示す

日付: 2026-11-24\
状態: 採用

## 背景

リンクの部品 `.link-underline` は、下線をホバーしたときだけ出していた。平常時の手掛かりは色だけで、実測ではアクセント色(`#0369a1`)と本文色(`#102733`)の比が 2.60:1、図の説明や補足に使う色(`#4a6572`)との比が 1.04:1 だった。`color` を指定していないリンクは本文と同じ色になる。指で触る端末にはホバーが無く、色の違いが分かりにくい人にはリンクと気づけない。このサイトは数値の出典へたどれることを約束しているので、出典のリンクが見つからないのは機能の欠落にあたる。

自動検査(axe)はこれを違反にしなかった。幅 0% の背景画像を「区別あり」と数えるためと見られる(推測)。

## 検討した選択肢

- **本文と出典だけ常時下線(採用)**: 手掛かりが色から独立する。ナビ・パンくず・見出し・カードの題名は、置き場所からリンクと分かるので今のまま
- **色を濃くする・差を広げる**: 本文色との差 3:1 と背景との 4.5:1 を両立する色は限られ、色だけの手掛かりであることは変わらない
- **すべてのリンクに下線**: 見出しとナビにも付き、要るところとの差が無くなる

## 決定

1. `main` の段落・図の説明・引用・定義の中の `.link-underline` と、箇条書きの直下のリンクに、平常時も実線の下線とアクセント色を付ける(平常時の線と引き直しの形は、姉妹サイトの edu-evidence・edu-watch・edu-law とそろえる。対象の範囲はサイトごとに違う)
2. 平常時の線は 1px で、文字の色の 70%。背景との比は両テーマで 3:1 以上を保つ。線は `border-bottom` で描く。ホバーとフォーカスではこの線を消してから、2px の線を左端から右へ引く(動きを減らす設定では動かさない)。どちらも border の箱の下端に置く
3. 用語の印(`.term-link`)は点線のままにし、実線と区別する
4. `tests/interactions.spec.ts` が、本文のリンクに下線があり色が地の文と違うこと、線の比と引き直し、見出し・ナビ・パンくずに無いことを見る

## 帰結

- 出典の多いページの印象が変わる
- `text-decoration` の下線と背景の線では、位置の基準(文字のベースラインと箱の下端)が違い、フォントごとにずれる。border と背景なら同じ箱なのでそろう
- `.link-underline` を新しい場所で使うときは、上の範囲に入るかで下線の有無が決まる

## 撤回 / 再検討の条件

- 本文のリンクを色以外の別の手掛かり(アイコンなど)で示すことにしたとき
