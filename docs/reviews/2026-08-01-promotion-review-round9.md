## ゲートが検出し是正した事項

### 1. 【事実誤り・2本に共通】「調査対象は公立学校の児童生徒(国立・私立は含まない)」

蔵書量・生活習慣の2体が**独立に同じ誤り**を指摘。令和7年度調査の実施要領は「国・公・私立学校の以下の学年の原則として全児童生徒を対象とする」。公立に限られるのは調査対象ではなく、**都道府県ごとに公表される集計**(実施要領の公表区分「都道府県ごと(都道府県教育委員会及び市町村教育委員会が設置管理する学校全体の状況)」)。主コンテキストで逐語確認のうえ、両データセットの caveats を「収録した集計の対象は公立学校の児童生徒です。調査自体は国・公・私立学校が対象ですが…」に是正。

### 2. 【事実誤り】ライセンス名が自前の証跡と矛盾(人口動態2本)

`license.name` を「政府標準利用規約(第2.0版)」としていたが、証跡 `raw/mhlw_chosakuken.html` に同文字列は **0 件**。厚生労働省の実際の記載は「権利表記の記載がない限り『**公共データ利用規約(第1.0版)**』(PDL1.0)に準拠」。サイトの法的表示に関わるため**全32データセットのライセンス表記を横断確認**したところ、影響は今回の draft 2本のみで published への波及はなかった。両データセットを PDL1.0 に是正し、e-Stat 側(政府標準利用規約 第2.0版準拠)と分けて記述。

### 3. 【事実誤り】自然増減率の説明が公表値を再現できない

`jinko-dotai-r6-todofuken` の列説明「出生率から死亡率を引いた値」に対し、公式定義は `年間自然増減数(出生数−死亡数) ÷ 10月1日現在日本人人口 × 1,000`。主コンテキストで検算したところ**48行中9行**(北海道・岩手・群馬・東京・神奈川・愛知・岡山・長崎・大分)で丸めの差により引き算では再現できない。data.csv の値は公表値どおりで正しく、誤っていたのは説明文のみ。定義どおりの記述に是正。

### 4. 【事実誤り】調査の実施期間が学年で異なる

`seikatsu-shukan-r7-todofuken` の caveats は「令和7年4月18日〜30日」のみとしていたが、原本注記は児童が「4月18日以降4月30日まで」、生徒が「**4月14日**以降4月30日まで」。実施要領でも生徒質問調査は理科と同日(4月14日〜17日)+後日実施と規定。両方を書き分けるよう是正。

### 5. 【誇張・誤読を招く表現】経年の説明

`jinko-dotai-keinen` の description は「合計特殊出生率は 1.72 から 1.54 へ低下」「離婚率はいずれも低下」としていたが、主コンテキストの検算で:
- 合計特殊出生率は**平成27年(沖縄1.96・全国1.45)をピークとする山型**で単調低下ではない
- 離婚率は**令和4年を底に直近2年が両者とも上昇**(沖縄 2.13→2.20→2.24、全国 1.47→1.52→1.55)。厚生労働省の報道発表も令和6年の離婚率を「前年の1.52より上昇した」と記載

いずれも実際の動きに合わせて是正。

### 6. 【裏づけのない一般化】「例年9月末公表」(学テ2本)

`updateFrequency` を「都道府県別の質問調査結果は例年9月末公表」としていたが、令和7年度の結果公表資料が3段階公表(7/14・7/31・9/30)を**当年度の改善点として**明記しており、令和6年度は都道府県別を含めて7月末に一括公表されていた。「例年」の裏づけがないため、令和7年度の実績と方式変更を明示する記述に是正。

### 7. 【証跡の不足】文科省ウェブサイト利用規約ページが raw に不在

学テ2本の `license.note` は「適用ドメインに nier.go.jp が明記されている」と述べるが、保存していた NIER 側 HTML にはドメイン一覧が含まれない。指摘を受けて `raw/mext_riyoukiyaku.html` を追加取得し、nier.go.jp の明記と「数値データは著作権の対象ではありません」を実見のうえ checksums.md5 に追記(100→101行)。

### 8. 【精度不足】再集計の対象年(人口動態2本)

「2004〜2017年に及んでいます」は連続範囲と誤読される。原典逐語は「平成16・18・21〜29年」= 2004年・2006年・2009〜2017年で、2005・2007・2008 は対象外。両データセットを列挙形式に是正。

## 検出したが是正不要と判断した事項

- `data.json` で `34.0` が `34` になる(26セル等)のは JSON 数値の正規化によるもので値は同一。表示は data.csv を読むため影響なし。既存データセットも同挙動。
- `jinko-dotai-r6-todofuken` の自然増減率は 47都道府県中1位(最も減少が小さい)だが、description は順位を主張しておらず控えめな記述にとどまっている。
- `seikatsu-shukan-r7-todofuken` の readingGuide「肯定合計では順位が変わりえます」は真(沖縄は6系列中4系列で順位が動き、小6就寝は29位→38位)。ただし**地図に出している小6起床は肯定合計でも47位のまま**であることが実測で分かったため、map.note にその旨を追記して地図の読みの頑健性を示した。
